# GVUI Core Features

This section documents the application-level features and UI subsystems of GVUI.

| Feature                                          | Description                                                                                                   |
| ------------------------------------------------ | ------------------------------------------------------------------------------------------------------------- |
| [In-Browser SQLite Caching](./sqlite-caching.md) | Multi-tier layout caching using WebAssembly SQLite (`sql.js`), deterministic keys, and LRU eviction.          |
| [Node Detail Drawer](./detail-drawer.md)         | Multi-tab diagnostic drawer: Overview, Cost & Tokens, Dependencies, Subagent Lineage, Error Inspector, Diffs. |
| [Graph Export Pipeline](./graph-export.md)       | Standalone SVG, high-resolution PNG, Mermaid diagrams, SQL DDL (SQLite/Postgres/MySQL), and offline HTML.     |
